# E-Commerce REST API (Node.js)

A backend service built with Node.js and Express to power an e-commerce mobile application.

> 🔗 **Mobile Client Repository:** https://github.com/ahmedelsayedabdelkaream/ecommerce-app

## Features
- **User Authentication:** JWT-based signup and login endpoints.
- **Product Routes:** Endpoints for fetching product listings and details.
- **Cart Routes:** Logic for managing user cart items and calculations.

## Tech Stack
- Node.js & Express.js
- JSON Web Tokens (JWT)
- Postman (API Testing)

## How to Run
1. `npm install`
2. Create a `.env` file based on `.env.example`
3. `npm start`
